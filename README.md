# ai-solution-lab

Kerangka 50 permasalahan dan produk solusi berbasis AI.

Repositori ini disusun untuk tugas mata kuliah Artificial Intelligence (AI) C oleh Tesya Putri Amalia. Setiap permasalahan memiliki satu folder berisi latar belakang, target pengguna, tiga produk solusi, dan rancangan korelasi digitalnya. Proyek ini masih pada tahap konsep, belum ada kode program.

Struktur:

- `pNN-nama-masalah/` : satu folder untuk setiap permasalahan
- `produk-a/`, `produk-b/`, `produk-c/` : dokumentasi tiap produk dalam folder masalah
- `docs/` : dokumen umum
- `.github/` : templat issue
- `CONTRIBUTING.md` : aturan kerja sama
