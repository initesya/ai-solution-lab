# Panduan Kontribusi

1. Setiap tugas dicatat sebagai issue menggunakan templat yang tersedia.
2. Kerjakan tugas pada branch tersendiri, dengan nama seperti `dok/p01-materi-kuliah`.
3. Tulis pesan commit yang singkat dan jelas.
4. Ajukan pull request dan minta peninjauan dari minimal satu anggota lain sebelum digabungkan ke `main`.
5. Keluaran dari alat AI, termasuk Hermes Agent, dianggap draf dan harus diperiksa sebelum digabungkan.
6. Jangan menyimpan data pribadi, kata sandi, atau token akses di dalam repositori.
